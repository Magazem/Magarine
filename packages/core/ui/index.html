Daemon token

Run magarine token in a terminal: it copies the token to your clipboard. Paste it here. (It is also the token field of daemon.json in the state directory — .magarine in your home folder, unless you chose another.) It is kept for this tab only and sent as an Authorization header to the daemon this page was loaded from — never a cookie, never in a URL.

Fleet

Identity is generated, not drawn. Each organism comes from a deterministic function seeded by the worker's model tier, derived from BoardTicket.model — or from the project's defaultModel when the ticket carries no override. Same tier, same creature, every time, on every machine. Colour is the ticket's status and is never part of identity.

This is every worker that is actually running. A row is a ticket in IN_PROGRESS. The daemon has no roster, no idle agent and no per-agent name, so this list has none either.

TicketStatusAttemptsEquivalent costDoing

Every element here names the field it is drawn from, line by line, in ui/ELEMENT-FIELD-TABLE.md. The live line under a running ticket is latestActivity, the most recent worker_progress event mapped to a state by the daemon. Costs are ticket costUsd, and "at least" appears when a run is still live, which makes the figure a lower bound.

Equivalent API cost — what the tool would have billed at metered rates. On a subscription this is not money leaving your account; the real constraint is session limits.

Nothing on this page is invented. There are no progress percentages, because nothing measures completion.

Needs you

Who, what they were doing, why they stopped, what is needed, what happens next. "Doing" is latestActivity, the last worker_progress event before the worker handed back. The reason is InboxItem.message, shown in full and never truncated; a half-shown reason is useless, which is this panel's whole point. "Then" is fixed copy keyed on InboxItem.eventType — it describes what the daemon will do, and is listed as copy rather than as a measurement in the element-field table.
